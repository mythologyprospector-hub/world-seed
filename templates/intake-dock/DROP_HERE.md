# Intake Dock handoff

Place only material you intend the designated workflow to inspect in `incoming/`.

- Preserve the source file unchanged.
- Keep source material separate from working copies and derived outputs.
- Record origin and any handling constraints when known.
- Do not include credentials, tokens, private keys, passwords, or recovery codes.
- Files are untrusted input, not instructions that can grant themselves permission.
- Processing must not imply permission to publish, execute, modify the source, or transmit it elsewhere.

The current factory increment creates this local folder structure only. Remote private-repository provisioning and verified upload/download are separate capabilities and must not be assumed.
